# Launch Checklist

This checklist should be completed before the Town of Mantee website goes live.

## Governance

- [ ] Confirm project owner.
- [ ] Confirm content approver.
- [ ] Confirm WordPress administrator.
- [ ] Confirm primary administrator and backup administrator.
- [ ] Confirm who publishes public notices.
- [ ] Confirm who publishes agendas and minutes.
- [ ] Confirm who maintains ordinance records.
- [ ] Confirm who updates permit information.
- [ ] Confirm who updates community center and event information.
- [ ] Confirm public records request routing: NEEDS_CONFIRMATION.
- [ ] Confirm whether the first launch is current-use first with historical archives backfilled later.
- [ ] Confirm website publication complements, but does not replace, any legally required notice channel unless properly approved.

## Domain and Hosting

- [ ] Confirm desired `.gov` domain.
- [ ] Confirm authorized municipal contact for `.gov` application.
- [ ] Confirm Login.gov access path for the authorized requester.
- [ ] Confirm domain administrator.
- [ ] Choose managed WordPress host after verifying current pricing, features, backups, staging, and support.
- [ ] Confirm ownership of hosting account.
- [ ] Configure DNS after domain approval.
- [ ] Enable HTTPS.
- [ ] Document renewal or billing process.
- [ ] Confirm staging environment is available before launch.

## Content Confirmation

- [ ] Confirm all contact information.
- [ ] Confirm office hours.
- [ ] Confirm Town office physical and mailing address.
- [ ] Confirm board meeting schedule.
- [ ] Confirm meeting location.
- [ ] Confirm public notice publishing workflow.
- [ ] Confirm available agenda and minutes archive.
- [ ] Confirm ordinance archive and codification status.
- [ ] Confirm building permit process.
- [ ] Confirm building permit forms.
- [ ] Confirm building permit fees.
- [ ] Confirm community center rental process.
- [ ] Confirm community center fees and rules.
- [ ] Confirm Farmers Market details.
- [ ] Confirm Walking Track details.
- [ ] Confirm Mantee Depot description.
- [ ] Confirm Mantee Heritage & History Museum description.
- [ ] Confirm event publishing process.

## Design and Assets

- [ ] Add approved local photography.
- [ ] Add approved Town logo or seal if available.
- [ ] Confirm image permissions.
- [ ] Add alt text to all meaningful images.
- [ ] Review mobile layout.
- [ ] Review tablet layout.
- [ ] Review desktop layout.

## Accessibility

- [ ] Verify current ADA Title II web accessibility requirements before launch.
- [ ] Use WCAG 2.1 Level AA as the planning target unless current guidance changes.
- [ ] Check heading order.
- [ ] Check keyboard navigation.
- [ ] Check color contrast.
- [ ] Check link text.
- [ ] Check form labels if contact form is used.
- [ ] Check PDF readability where practical.
- [ ] Avoid scanned-image PDFs when searchable files are available.
- [ ] Add file type, date, and size to PDF links where practical.
- [ ] Create a remediation backlog for older inaccessible scans.
- [ ] Add accessibility statement if approved: NEEDS_CONFIRMATION.

## WordPress Setup

- [ ] Install lightweight theme.
- [ ] Prefer native block theme and block editor unless staff review shows otherwise.
- [ ] Configure navigation.
- [ ] Configure homepage.
- [ ] Configure public notice records.
- [ ] Configure meeting records.
- [ ] Configure ordinance records.
- [ ] Configure forms/documents records if needed.
- [ ] Configure event records if needed.
- [ ] Configure user roles.
- [ ] Limit administrator accounts.
- [ ] Configure multi-factor authentication where possible.
- [ ] Configure backups.
- [ ] Test backup restore access.
- [ ] Configure security settings.
- [ ] Configure spam protection if forms are used.
- [ ] Configure search.
- [ ] Install only approved launch plugins.

## Pre-Launch QA

- [ ] Review every page for `NEEDS_CONFIRMATION`.
- [ ] Remove or resolve unapproved draft content.
- [ ] Test all navigation links.
- [ ] Test all document links.
- [ ] Test Facebook share previews if used.
- [ ] Test site on a phone.
- [ ] Test site on a slower connection if possible.
- [ ] Confirm no private documents are uploaded.
- [ ] Confirm analytics decision: NEEDS_CONFIRMATION.
- [ ] Confirm current-use records are published before historical backlog work delays launch.
- [ ] Confirm older archive gaps are documented if applicable.

## Launch

- [ ] Board or authorized approval received.
- [ ] DNS pointed to live website.
- [ ] HTTPS working.
- [ ] Search engine indexing decision confirmed.
- [ ] Facebook announcement links to official website.
- [ ] Internal maintenance SOP shared with responsible staff.
- [ ] Historical archive backfill queue started after launch if needed.

## Post-Launch

- [ ] Review site after first public notice posting.
- [ ] Review site after first meeting agenda/minutes posting.
- [ ] Schedule monthly content review.
- [ ] Schedule quarterly records archive review.
- [ ] Document any resident feedback.
