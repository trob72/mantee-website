# Maintenance SOP

This starter standard operating procedure describes how the Town of Mantee website can be maintained after launch. It should be reviewed and adjusted by the Town before adoption.

## Maintenance Goals

- Keep official public information current.
- Make updates simple for designated staff.
- Preserve public records in a predictable structure.
- Keep costs low.
- Avoid dependence on a single person where possible.

## Roles

Needs confirmation:

- Website administrator, preferably limited to essential admin duties
- Backup administrator
- Content editor
- Public notices approver
- Meetings records owner
- Ordinance records owner
- Permit information owner
- Community center information owner
- Events calendar owner
- Backup contact

Recommended access posture:

- Keep administrator accounts limited.
- Give routine publishers editor-level or custom role access where possible.
- Use contributor access only for draft-only contributors.
- Require multi-factor authentication for administrator and editor accounts where possible.

## Weekly Tasks

- Review homepage for outdated notices.
- Check upcoming meetings and events.
- Confirm any new public notices have been posted.
- Confirm Facebook posts link back to the official website when applicable.
- Check contact page for accuracy if any office information changed.
- Review form inboxes if forms are enabled.

## Monthly Tasks

- Post agendas according to the confirmed meeting workflow.
- Upload approved meeting minutes.
- Archive expired public notices according to confirmed Town practice.
- Review building permit page for changes.
- Review community center information.
- Check for broken links.
- Confirm WordPress, theme, and plugin updates are handled by the managed host or administrator.

## Quarterly Tasks

- Review ordinance archive for missing records.
- Review content inventory.
- Review user accounts and remove access no longer needed.
- Check backup process.
- Test or schedule a restore test according to the backup plan.
- Review accessibility basics on high-use pages.
- Review photo permissions and media library organization.
- Review pending plugin updates and remove plugins no longer justified.

## Annual Tasks

- Archive prior-year records according to confirmed Town practice.
- Review naming conventions.
- Review this SOP.
- Review content ownership.
- Review plugin list and renewal costs.
- Confirm records retention or archive guidance still fits Town requirements: NEEDS_CONFIRMATION.

## Public Notice Posting Workflow

1. Receive approved notice content or approved PDF.
2. Confirm posting date and category.
3. Create a Public Notice record in WordPress.
4. Add approved HTML text where practical.
5. Attach the approved PDF when the document itself matters.
6. Add a short summary only if approved.
7. Use descriptive file links with file type, date, and size where practical.
8. Publish the website notice.
9. Share the website notice URL on Facebook if needed.
10. Archive or expire according to confirmed Town practice.

## Meeting Posting Workflow

1. Confirm meeting date, time, and location.
2. Confirm governing body and status label.
3. Upload agenda using the records naming convention.
4. Add packet, remote meeting, or video information only if applicable and approved.
5. Publish the meeting record or update the Meetings page.
6. After approval, upload minutes using the records naming convention.
7. Link agenda and minutes under the same meeting record if possible.

## Ordinance Posting Workflow

1. Confirm ordinance record is approved for publication.
2. Confirm ordinance number, title, and adoption date.
3. Upload original PDF or scan.
4. Publish ordinance record with factual metadata only.
5. Avoid summaries or interpretations unless approved.

## Building Permit Updates

Before updating the Building Permits page, confirm:

- Permit types
- Application steps
- Fees
- Forms
- Review timeline
- Inspection contacts
- Office hours or submission options

All unconfirmed changes should remain draft.

## Community Center Updates

Before updating the Community Center page, confirm:

- Facility availability
- Rental process
- Fees
- Rules
- Capacity
- Calendar process
- Contact information

Do not publish rental rules or fees until approved.

## Event Updates

Recommended event fields:

- Event title
- Date
- Time
- Location
- Organizer
- Contact
- Description
- Flyer or image
- Approval status

Only approved events should be published as official Town events.

## Emergency or Urgent Information

Emergency posting workflow is NEEDS_CONFIRMATION.

Items to define:

- Who can authorize urgent website updates
- What qualifies as urgent
- Whether Facebook is used for distribution
- Whether homepage banner is used
- How urgent items are removed or archived

## Account Safety

- Use named accounts where possible.
- Use strong passwords.
- Use multi-factor authentication where available.
- Keep administrator access limited.
- Remove old users promptly.
- Store recovery information in an approved Town-controlled location.

## Backup and Recovery

Backup workflow is NEEDS_CONFIRMATION.

Recommended planning target:

- Primary live site copy on managed host.
- Automated host backups.
- Independent off-site backup if host backups do not satisfy Town expectations.
- Quarterly restore test.
- Documented recovery contact and recovery steps.

## Change Log

Recommended practice:

- Keep a simple log of major site changes.
- Record date, page, summary, and person making the update.
- Keep the log internal unless the Town chooses otherwise.
