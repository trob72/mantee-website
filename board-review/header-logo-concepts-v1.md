# Header And Logo Concepts v1

This is a board/staff discussion aid, not an approval document.

Prototype concept board:

- `prototype/header-concepts.html`

Live preview after GitHub Pages deploy:

- `https://trob72.github.io/mantee-website/header-concepts.html`

## Purpose

The current prototype uses a temporary `M` mark. Before creating or selecting a permanent logo/header direction, the board can react to a few broad approaches.

The goal is to answer:

- Which direction feels most appropriate for Mantee?
- Should the first launch use a simple text-first mark or a local landmark-inspired mark?
- Does a sticky translucent header feel appropriate for the official Town website?
- Are there symbols, local references, or wording choices that should be avoided?

## Concepts Included

### Concept A: Official Civic

Traditional municipal direction with a simple seal-style mark.

Best if the Town wants the safest and most formal look.

### Concept B: Depot and Heritage

Heritage-focused direction inspired by the Depot, museum, and local history.

Best if the Town wants community identity to feel prominent.

### Concept C: Water Tower Landmark

Landmark-focused direction that pairs with the existing aerial photography.

Best if the Town wants something distinctly local while staying official.

### Concept D: Text-First Official

Minimal direction using strong typography and a restrained monogram.

Best if the Town is not ready to approve a permanent mark before launch.

## Sticky Header Concept

The concept board includes a static mockup of a sticky translucent header similar in spirit to the reference-site behavior.

If selected later, implementation should confirm:

- Strong contrast over all photos.
- Compact mobile behavior.
- Clear menu/dropdown behavior.
- Accessibility and keyboard usability.
- No obstruction of important page content.

## Recommended Feedback Prompt

Ask reviewers:

```text
Please review these as visual directions only, not final logos.

1. Which concept feels most appropriate for Mantee?
2. Which concept feels least appropriate?
3. Should the first launch use a simple text-first mark or a local landmark mark?
4. Does the translucent sticky header feel professional and useful?
5. Are there any symbols or wording choices we should avoid?
```

## Notes

- None of these concepts are approved Town seals.
- Final logo/header decisions should be documented in `docs/decision-log.md`.
- Any official seal, mark, or local historical reference should be confirmed before launch.
