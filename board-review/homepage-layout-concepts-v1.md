# Homepage Layout Concepts v1

This is a discussion aid for reviewing homepage shortcut/button layout. It is not a final homepage change.

Prototype concept board:

- `prototype/homepage-layout-concepts.html`

Live preview after GitHub Pages deploy:

- `https://trob72.github.io/mantee-website/homepage-layout-concepts.html`

## Purpose

The current homepage hero uses large shortcut buttons. Some of those repeat the main navigation directly, such as Resident Services appearing both in the top navigation and in the hero button row.

The goal is to compare alternate button layouts before changing the real homepage.

## Concepts Included

### Option 1: Focused Utility Buttons

Keeps large buttons in the hero but swaps out redundant items for higher-value actions.

Possible hero buttons:

- Public Notices
- Meeting Records
- Building Permits
- Contact the Town

### Option 2: Grouped Start Here Bar

Moves away from exact page names and uses broader resident task groups.

Possible groups:

- Government Records
- Resident Help
- Community Facilities
- Contact

### Option 3: Hero Plus Quick Cards

Recommended starting direction.

Keeps the hero cleaner, uses only one or two primary actions in the hero, and places practical shortcut cards immediately below.

Possible structure:

- Hero action: Latest Notices
- Hero action: Contact the Town
- Quick cards: Records, Permits, Facilities, Community

### Option 4: No Hero Buttons

Makes the hero purely identity-focused and moves all action paths below the first screen.

This is the cleanest visually but may be less useful for residents who want an immediate path.

## Recommended Feedback Prompt

Ask reviewers:

```text
Please review these as homepage layout directions only.

1. Which option feels easiest for residents?
2. Which option feels least repetitive with the top navigation?
3. Should Contact remain in the hero?
4. Should Building Permits be promoted more than general Resident Services?
5. Are any first-screen shortcuts missing?
```
