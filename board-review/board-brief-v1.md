# Board Brief: Town of Mantee Website Planning and Prototype

## Purpose

This project creates the planning foundation and static prototype shell for an official Town of Mantee website.

The website is intended to be a low-cost, professional public information hub that can later be built in managed WordPress.

## Why This Matters

- Residents need one official source for Town information.
- Public notices, meetings, ordinances, permits, and services should be easier to find.
- Facebook can continue to distribute updates, but the website should hold the official information.
- A simple managed WordPress site can be maintained at lower cost than a custom application.
- A future `.gov` domain can strengthen trust and official identity.

## Implementation Report Notes

The provided practical implementation report supports the current direction:

- Managed WordPress is the preferred production platform.
- A `.gov` domain should be pursued through the authorized government request process.
- The native WordPress block editor is preferred over a heavy page builder.
- The first launch should focus on current-use public information rather than waiting for every historical record to be digitized.
- Historical records can be backfilled after launch in a prioritized archive queue.
- Facebook should share links back to the official website rather than serve as the only source.

Product choices, prices, legal requirements, accessibility requirements, and procurement steps must be verified before final approval.
