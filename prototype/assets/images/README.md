## Photo Rules

- Use only photos approved for public website use.
- Avoid identifiable people unless publication permission is confirmed.
- Keep original high-resolution photos outside the prototype folder.
- Put web-ready copies in this folder.
- Use descriptive alt text when replacing placeholders in HTML.
- Prefer `.jpg` or `.webp` for real photos.

## Practical Export Sizes

- Wide backdrops: 1600px wide, 16:9 or wider.
- Cards and page photos: 1200px wide, 16:9.
- File size target: under 500 KB per image where practical.
